# 文法部分方案

## 目标与结构
- 目标：让用户从“规则理解”→“例句感知”→“对比辨析”→“应用练习”。
- 核心结构：文法点 → 示例 → 练习 → 复习。

## 数据层规划（基于现有结构）
- 数据文件：`grammar-n1.json` ~ `grammar-n5.json`
- 关键字段：
  - `pattern`（展示用）
  - `formation`（接续结构）
  - `meaning_cn` / `usage`（解释）
  - `examples`（例句）
  - `notes`（补充/易错/对比）
  - `sentenceTags`（真题标记）
- 可选扩展：
  - `tags`（功能/对比/语气分类）
  - `difficulty`（1~5，用于排序或推荐）

## 界面与体验
1) 文法列表页
   - 展示：`pattern + formation + meaning_cn`
   - 支持：紧凑/展开（与词汇页一致）
2) 文法详情页
   - 结构：pattern → 形成 → 释义 → 用法 → 例句 → 备注 → 真题标签
3) GrammarCard
   - 作为统一展示组件，复用于列表与详情

## 学习路径
- 学习模式
  - 卡片式浏览（主模式）
  - “例句优先”模式：先看例句再显示解释
- 练习模式
  1) 选择题：给例句选正确文法（MCQ）
  2) 填空题：例句缺一个文法
  3) 对比题：A/B 结构辨析（来自 `notes` / `tags`）
- 复习模式
  - 复用词汇的进度/错题机制
  - 以 `id` 为基础记录正确/错误/间隔复习

## 推荐节奏
- 初期：每关 8~12 条文法（可与 `STAGE_SIZE` 对齐）
- 复习：按“错误率 + 间隔”优先推送

## 实施顺序（建议）
1) 文法列表 + 详情页
2) 复用现有设置（compact/字体缩放）
3) 文法练习模式（MCQ + 填空）
4) 复习与错题
5) 文法对比功能（基于 tags/notes）

## 统计口径（建议）
1. 正确率统一口径：`正确数 / (正确数 + 错误数)`。
2. 连续学习按自然日计算，当天有任意一次作答即计入 1 天。
3. 标签只升不降，解锁后永久保留。
4. 同类标签在首页可只展示最高等级，成就页展示全部已解锁标签。

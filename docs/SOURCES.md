# Vocabulary Sources

This project bundles open-source datasets from the following sources:

1) JMDict (EDRDG)
- Source: https://www.edrdg.org/
- Notes: Uses the JSON build from jmdict-simplified.
- License: JMDict/EDRDG (see CC BY-SA 4.0)

2) Open Anki JLPT Decks
- Source: https://github.com/jamsinclair/open-anki-jlpt-decks
- Notes: JLPT N5-N1 lists with English meanings.
- License: MIT

Full license texts should be included in release builds.

# App 总体设计（JLPT 学习）

## 摘要
面向 JLPT N5–N1 学习者的离线学习应用，覆盖词汇与文法两条学习线。采用关卡制与练习题型组合，内置静态数据包与本地进度存储，目标是形成完整学习闭环（学习→测验→复习→统计）。

## 目标与成功标准
- 目标：用户在离线情况下完成词汇与文法学习、测验与进度跟踪。
- 成功标准：
  - 学习流程可用：选级别 → 列表 → 学习/闯关 → 结算 → 复习。
  - TTS 可用（日语）。
  - 题型覆盖：选择题/拼写/听写/填空等。
  - 数据覆盖 JLPT N5–N1，可按级别切换。

## 范围与非目标
- 范围：离线词库与文法库、关卡机制、学习/测验、错题本、基础统计。
- 非目标：账号系统、云同步、社交功能、在线词库更新。

## 架构设计
- 技术栈：React Native + Expo + TypeScript
- 状态管理：Zustand
- 本地存储：SQLite（expo-sqlite）保存词汇/文法/进度/设置
- TTS：expo-speech（优先系统 TTS）
- 题目生成：本地算法生成

## 数据与版本管理
- 数据包版本号写入 settings，用于检测数据变更。
- 版本变化时重建基础表，并尽量保留用户进度。

## 功能模块（总览）
- 词汇学习线：关卡学习 + 题型测验 + 错题/统计
- 文法学习线：卡片学习 + 例句理解 + 练习与复习
- 设置：TTS、题型占比、显示样式等
- 错题本：支持“词汇/文法”切换与紧凑模式切换

## 关键界面（MVP）
- 启动页 / 级别选择页（N5–N1）
- 词汇：关卡列表、闯关测验、结算、错题本
- 文法：列表页、详情页、练习页
- 我的页：今日学习、五十音图入口、动词变形表入口、设置入口
- 五十音图页
- 动词变形表页
- 设置页（从“我的”页进入）

## 导航栏设计
- 形式：底部 Tab 导航（移动端主导航），顶部保留返回与页面标题。
- Tabs：
  - 词汇：进入词汇学习线（关卡/闯关/错题）。
  - 文法：进入文法学习线（列表/详情/练习）。
  - 搜索：词汇/文法搜索。
  - 复习：统一入口（词汇 + 文法的错题与复习）。
  - 我的：今日学习、工具入口与设置入口。
- 导航结构：
  - 各 Tab 内使用 Stack 导航（列表 → 详情/闯关 → 结算）。
  - 复习 Tab 内可切换“词汇/文法”子分类。
  - 我的 Tab 内包含：五十音图、动词变形表、设置等工具页。
- 体验细节：
  - Tab 显示当前学习级别（N5–N1）的小标签。
  - 复习 Tab 显示待复习数量徽标。

## 交付步骤（实施顺序）
1) 词汇基础闭环（已有基础）
2) 文法基础展示与学习
3) 文法练习与复习
4) 统计与体验优化

## 假设与默认选择
- 使用系统 TTS
- 首版不做账号与云同步
- 数据包随版本更新
